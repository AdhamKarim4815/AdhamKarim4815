# Hi, I'm Adham Karim

I'm a Commerce student at the University of Toronto (Rotman Commerce), specializing in management with a focus on finance and data science in business. I build finance and data tools: valuation models, risk analytics and market research systems. Every project below has tests, a methodology write-up and a clear statement of its limits. Data in the repos is synthetic or illustrative unless stated.

**Try them live:** [DCF Studio](https://adhamkarim4815.github.io/dcf-studio/) · [Options Lens](https://adhamkarim4815.github.io/options-lens/) · [Retirement Monte Carlo](https://adhamkarim4815.github.io/retirement-monte-carlo/)

**Tools I work in:** Python (numpy, scipy, pandas), Excel (live-formula models), JavaScript and TypeScript, Swift, SQL.

## Corporate finance and valuation

| Project | What it is |
|---|---|
| [three-statement-model](https://github.com/AdhamKarim4815/three-statement-model) | Integrated income statement, balance sheet and cash flow forecast. A live-formula Excel workbook reconciled cell by cell to a Python engine, with scenarios and balance checks. |
| [lbo-lab](https://github.com/AdhamKarim4815/lbo-lab) | Leveraged buyout model with sources and uses, debt tranches, cash sweep, returns, a value creation bridge and sensitivity tables. Excel and Python agree on thousands of checked values. |
| [dcf-studio](https://github.com/AdhamKarim4815/dcf-studio) | Interactive DCF valuation in the browser, with WACC and terminal growth sensitivity. |
| [statement-ratios](https://github.com/AdhamKarim4815/statement-ratios) | Ratio analysis from financial statements: DuPont, Altman Z-score and Piotroski F-score. |
